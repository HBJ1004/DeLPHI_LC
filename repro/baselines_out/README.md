# Reference baselines

The DeLPHI blocks in these JSON and NPZ files are historical v1.0.0 results.
Only the standard-pole and random-axis rows are current reference baselines.

For the paper's retrained DeLPHI results, use
`retrain-20261030/results/median-stats.json` and
`retrain-20261030/results/headline/maps/own-period/analyses/summary.json`
from the v1.1.0 data record. The producers are
`repro.own_period.maps.analyses` and `repro.own_period.median_stats`.
